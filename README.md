# 🛒 E-Commerce Sales & Customer Analysis
End-to-end Data Analyst portfolio project covering SQL analysis, Excel data preparation, Power BI dashboard development, and business recommendations based on an e-commerce transactional dataset.

## 📌 Project Overview

This project analyzes e-commerce transactional data to identify sales performance, customer behavior, shipping efficiency, payment preferences, and product review trends. The objective is to transform raw transactional data into actionable business insights using SQL, Excel, and Power BI.

---

## 🎯 Business Objectives

- Analyze overall sales performance.
- Identify top-performing product categories.
- Understand customer purchasing behavior.
- Evaluate shipping performance.
- Analyze payment method usage.
- Measure customer satisfaction through product reviews.
- Build an interactive dashboard for business decision-making.

---

# 🛠 Tools Used

- SQL (SQLite / DBeaver)
- Microsoft Excel
- Power BI Desktop

# 📂 Dataset

The project consists of six datasets:

| Dataset | Description |
|----------|-------------|

| orders.csv | Order transactions |

---

# 💡 Key Business Insights

Some important findings include:

- Revenue fluctuated throughout the observation period with several seasonal peaks.
- A few product categories generated the highest contribution to total revenue.
- Customer purchases were distributed across multiple payment methods without one method overwhelmingly dominating.
- Shipping performance was generally stable, although some statuses require operational improvement.
- Customer ratings indicate overall positive satisfaction while highlighting opportunities for service enhancement.

Detailed findings are available in the Business Findings report.
